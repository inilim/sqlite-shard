# Инструкция по формированию отчетов и тестов публичного API: `Inilim\SqliteShard\Registry`

Область — публичный API класса `Inilim\SqliteShard\Registry`.

> **Статусы покрытия** (проставлены по фактическому набору тестов `tests/Registry/*`):
> `[x]` — кейс покрыт тестом; после тире перечислены покрывающие тест-методы (`Класс::метод`).
> `[]` — кейс не покрыт ни одним тестом.

## Общие договорённости

1. Каждый кейс выполняется в отдельной пустой временной директории; после теста все созданные файлы удаляются.
2. Описания тест-кейсов пишутся на языке предельной ясности. Каждое описание однозначно называет: какой метод/операция вызывается, при каком подготовленном состоянии (числа, таймауты, `updated_at`, границы `<=`/`>`/ровно) и какой результат проверяется (исключение с именем класса, булев результат, число, изменение состояния). Оценочные слова без конкретики — «работает», «правильно», «корректно», «соответствующим образом» — не используются: вместо них называется наблюдаемый факт. Если поведение не является гарантией (например, гонка аренды), пишется «проверяется»/«детектор», а не «гарантируется»/«ожидается».
3. В файлах method_*ИмяМетода*_test_cases.md строго должны быть список тест кейсов, пункты покрытия, описания, и название тестов которые покрывают тест.
4. Запрещено создавать вспомогательные классы или методы "фабричные обертки". Все делаем инлайново, за исключением технических моментов которые требуют отдельных методов.

### Термины

- **Реестр/Registry** — Обьект Registry и файл `registry-{sha1(name)}.sqlite` в `baseDir`.
- **Шард/Shard** — Обьект Shard и запись в таблице реестра и файл `{id}.sqlite` в `baseDir`.
- **`rent_timeout`** — время после которой shard будет просрочен. if(updated_at <= (time() - rent_timeout)) ? просрочен : активен.
- **Активный шард/shard** — шард с `active = 1`, у которого `updated_at` больше `time() - rent_timeout`.
- **Просроченный шард/shard** — шард с `active = 1`, у которого `updated_at` меньше либо равен `time() - rent_timeout`.
- **Свободный шард/shard** — существующий шард, у которого `active = 0` либо который просрочен.
- **Остаток аренды** — `updated_at - (time() - rent_timeout)`, но не меньше нуля; для неактивного шарда — `-1`.
